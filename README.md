# 📖 Description


Adds 30+ brand-new vanilla-like structures to the game

There are dedicated versions for only the [Villages](https://modrinth.com/datapack/katters-structures-only-village), [Dungeon](https://modrinth.com/datapack/katters-structures-only-dungeon) and [Ambient](https://modrinth.com/datapack/katters-structures-only-ambient) Structures as well as the [Deep Blue Dimension](https://modrinth.com/datapack/katters-structures-deep-blue).

There is also an official [Resource Pack](https://modrinth.com/resourcepack/katters-structures-resource-pack)

# 💬 Dialog/ Gamerules

From KS version 2.3 and MC version 1.21.6 Katters Structures has the new Dialog function.

These allow you:

- as Admin/ OP: 
  - To give yourself any special Item in the Pack
  - Change the Gamerules of KS:
    - This Includes Disabling all Bosses,
    - Disabling entrance to the Deep Blue,
    - Disabling the use of Custom Models,
    - Disabling Bossbars
- as a normal User:
  - look up a Pack FAQ

as Admin: ```/function kattersstructures```

as User: it's found in the pause menu

❗ Disabling Bosses or the Deep Blue will not disable the structures/ dimension itself. It will only disable the spawning of them or the functionality of already spawned ones.

Sadly, it's not possible to disable Structures via Code in Datapacks

# 🛠️ How to, Instructions
The datapack usually just needs to be installed. There is nothing else you have to do. It just works out of the box.

For **PaperMC users**, it is recommended to set the `paper.maxChatCommandInputSize` property to a value between 512 and 1024. More information can be found in the [PaperMC Docs](https://docs.papermc.io/paper/reference/system-properties/#papermaxchatcommandinputsize). Also make sure to have `allow-non-player-entities-on-scoreboards` enabled in your paper configs.

**The data pack version also doubles as a resource pack. So in order to be able to see them, just place the data pack .zip also in your resource folder and activate it like any other resource pack.**

Or download the official [Resource Pack](https://modrinth.com/resourcepack/katters-structures-resource-pack).
